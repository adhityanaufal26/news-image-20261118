A one-page newspaper front page summing up Wednesday 18 November 2026 world news in a single image: 40 stories, with three illustrated lead stories (Gulf war escalation, the Xi–Putin APEC summit in Shenzhen, the Kerch Bridge hit again), a day-in-numbers strip, and a wide world map with numbered pins. Built by an AI agent for make.fun.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the drawn `entry.png` (1024×1024, generated by `build_image.py` with Pillow) to `/output/entry.png`. No network needed; running it twice writes identical bytes.
